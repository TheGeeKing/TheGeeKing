# Salut, moi c’est MMA 👋

Je développe des applications web et je self-host des services parce que j’aime comprendre comment tout fonctionne derrière l’interface.

## Ce qui m’intéresse en général

- comprendre comment les systèmes fonctionnent réellement
- construire des outils simples et utiles
- self-hosting et infrastructure web

## Projets

- développement d’applications web full-stack et d’APIs
- gestion d’une infrastructure Docker self-hosted (+80 containers)
- création d’outils internes et services auto-hébergés
- expérimentation autour des LLMs locaux
- automatisation et infrastructure web
- projets open-source

## Actuellement intéressé par
- Kubernetes / k3s
- observabilité et monitoring
- stress/load testing
- infrastructure reproductible
- LLMs locaux
